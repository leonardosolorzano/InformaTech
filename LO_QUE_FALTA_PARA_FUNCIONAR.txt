ESTADO DEL PROYECTO INFORMATETECH
=================================

El proyecto funciona en local sin Docker usando SQLite.

SERVICIOS:
- Backend FastAPI: http://localhost:8000 (docs en /docs, health en /health)
- Frontend Next.js: http://localhost:3000

CREDENCIALES ADMIN:
- Email: admin@example.com
- Username: admin
- Password: Admin12345

ARRANQUE:
```bash
./scripts/dev.sh
```

El script aplica migraciones, carga los datos iniciales y arranca backend y frontend.
Para detenerlos: Ctrl+C.

ARRANQUE POR SEPARADO:
```bash
# Backend
.venv/bin/alembic upgrade head
.venv/bin/python -m app.initial_data
.venv/bin/uvicorn app.main:app --reload --port 8000

# Frontend (otra terminal)
cd web && pnpm dev --port 3000
```

NOTAS:
- La configuración local está en `.env` (SQLite: `sqlite:///./technews.db`).
- Docker es opcional; `docker compose up --build` usa PostgreSQL.
- Si hay errores por cachés antiguas: `./scripts/limpiar-cache.sh`.
